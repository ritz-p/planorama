Generation settings

Changing a setting cancels generation and clears the previous result. Generate again to apply your settings.

HTML diagnostics (optional)

Requires HTML output. Both are off by default. Separate panels show unresolved relationships and final geometry findings for the selected view. Findings are bounded; panels distinguish unavailable collection, zero findings, incomplete input and omitted entries. This is not a complete analysis: cross-state mapping diagnostics and provider evidence are unsupported.

Spatial resource types (optional)

Show selected resource types in the spatial diagram. With none selected, these resources remain Logical. Reference details are retained.

Find focus in original input

Choose one exact address or edit focus above. Listed resources may be excluded by selection filters. Current and deposed objects sharing an address form one row; generation may reject an ambiguous address. Historical objects cannot be selected individually.

Enabled only with a focus address. Empty uses depth 1; otherwise enter a nonnegative integer (0–4294967295). Clearing focus preserves this input but excludes it from generation.

Modules (optional)

Add one complete module selector per row. Spaces, commas, dots and quotes are preserved. No rows means no module filter. Empty rows must be filled or removed. Duplicate selectors are passed unchanged to the generator and select the same resources once.

Original input counts include managed/data and current/deposed objects. Subtree includes direct resources; overlapping rows must not be added together. Configuration rows aggregate backed instances, including zero when none are known. Root cannot be selected.
